# Positivus – React

HTML to React conversion of the Positivus landing page (Vite + React).

## Run locally
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```

## Structure
- `src/data/data.js` – all content (arrays of objects) in one place
- `src/components/ui/` – reusable UI (Button, SectionTitle, Logo, ArrowLink)
- `src/components/` – page sections and cards
